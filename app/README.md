# Clifford Ray portfolio app

This folder contains the portfolio landing page, project summaries, an animated SVG system map, a read-only interactive terminal, and a client-side architecture model.

Open `index.html` in a browser to view it. The page has no build step or runtime dependencies. Google Fonts load from Google's font CDN; system font fallbacks are defined in `styles.css`.

The terminal accepts only the fixed commands shown on the page; it does not execute shell commands or send input to a server. The architecture model uses illustrative formulas in the browser; it does not measure a real service. The service map is an SVG illustration, not a live WebGL rendering. The case study summaries are placeholders for the detailed breakdowns listed in the roadmap. Replace them with reviewed project facts and add approved contact details before publishing.
